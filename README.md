# 机场地面保障调度管理系统

面向航班机位分配、廊桥调度、行李转运、货物装卸、航空加油、航食配餐与客舱清洁全流程的机场地面保障调度管理平台。

这是一个**纯前端**管理平台：Vue 3 + Vite + TypeScript，仓库里没有后端服务。业务数据由
`frontend/src/data/` 下的本地数据层提供：首次打开用示例数据播种，之后的登记、筛选与状态流转
结果都持久化在浏览器 `localStorage` 里，刷新或重开浏览器都还在。dev server 已关掉自动打开页面，
启动后按终端打印的地址手工打开。

## 目录结构

```text
.
├── frontend/                 Vue 3 + Vite + TypeScript 前端（唯一运行单元）
│   ├── src/views/            每个业务模块一个页面
│   ├── src/api/local-service.ts   本地数据服务：列表、筛选、动作流转、导出
│   ├── src/data/             模块元数据 / 示例数据 / localStorage 持久化
│   ├── src/stores/           会话与筛选状态
│   └── vite.config.ts        dev server 配置（open: false，无 /api 代理）
├── .gitignore
└── docker-compose.yml
```

## 启动

```bash
cd frontend
npm install
npm run dev
```

前端默认监听 `http://127.0.0.1:5173/`，dev server 不会自动打开浏览器，需要自己访问。

生产构建：

```bash
cd frontend
npm run build
```

## 约定

- 每个模块的页面在 `frontend/src/views/<模块>/index.vue`，页面只负责渲染，读写统一走
  `frontend/src/api/local-service.ts`。
- 字段、状态、动作与流转目标集中在 `frontend/src/data/modules.ts`；示例数据在
  `frontend/src/data/seed.ts`。
- 状态流转只允许在 `local-service.ts` 里改，页面组件不做业务判断。
- 想回到初始数据：清掉浏览器里 `airport-ground-handling:entries` 这一项，或调用 `resetModule(模块)`。

## 运营概览 / 航站楼态势 / 交班

- 运营概览（`/`）有三个视图：**业务模块汇总**、**航站楼态势**、**交班工作台**。
  航站楼态势把 18 个业务模块在 T1/T2 两座航站楼的「登记总量、待处理、异常量」分别列出。
- 记录到航站楼的归属解析在 `frontend/src/data/areas.ts`，回填优先级由高到低：
  1. **P1 机位直查**：所属机位 / 推出机位 / 安装位置 → 机位-航站楼主数据；
  2. **P2 航班反查**：匹配 / 关联 / 涉及航班 → 航班-机位表 → 航站楼；
  3. **P3 区域线索**：巡查区域、事发位置、班组、备注等文本里的 T1/T2 线索；
  4. **P4 模块兜底**：车辆/排班/设备类集中待命模块归 T1，其余默认 T1。
  缺机位归属的存量记录迁移时按此顺序回填，不臆造机位号。
- 交班工作台把「航站楼 × 业务模块」渲染成交接格：值班主管可上移/下移排列、填写交接说明、
  **锁定快照**。点「交班确认并封存」后：
  - 所有格子按当前统计规则拍快照，封存成一个只读版本；
  - 机坪安全台账（`apron_safety`）对每个有待处理/异常的格子生成一条「待巡查」交班待办，
    带交班版本号可追溯；
  - 概览顶部结论与「保障清单」页（`/handover`）读的是同一份封存文档（单一结论来源）。
- **并发封存只保留首个版本**：封存用 CAS 令牌（`sealToken`），成功即轮换并开出新一轮草稿；
  另一标签页先封存会触发 `storage` 事件刷新，后到的确认因令牌对不上被拒绝。工作台里有
  「模拟另一标签页并发封存」按钮可直接验证。
- **统计规则换版只改未锁格**：规则版本在 `frontend/src/data/stats.ts`（v1 沿用旧口径，
  v2 把异常滞留/中断、故障停用、超时、待整改等显式异常状态也计入异常量）。切换版本时未锁格子
  实时重算；已锁格子保留锁定时快照并标记「历史快照」，绝不改写，解锁后才按新版重算。

## 本地数据槽位

| localStorage 键 | 内容 |
| --- | --- |
| `airport-ground-handling:entries` | 各模块登记记录（schema v2：`{ schemaVersion, entries }`） |
| `airport-ground-handling:board` | 交班工作台草稿：格子排序、锁定、快照、规则版本、CAS 令牌 |
| `airport-ground-handling:handovers` | 已封存的交班版本（只读） |

旧版（只存扁平 `Record<模块, 记录[]>`）首次打开会自动迁移到 v2：与新种子合并、按 P1→P4
补航站楼归属，并在 `airport-ground-handling:meta` 记录迁移时间。
